# Faculdade — Sistemas para Internet (IFTM Uberlândia Centro)

Material do curso organizado por **período → disciplina → categoria**.

```
N-periodo/<disciplina>/{aulas, atividades, projetos, provas}
```

| Período | Disciplinas |
|---|---|
| 1º | empreendedorismo · fundamentos-de-sistemas-para-internet · logica-de-programacao · projeto-website-estatico · requisitos · sistemas-operacionais |
| 2º | algoritmos-e-programacao · fundamentos-de-banco-de-dados · javascript-basico · programacao-orientada-a-objetos-1 · projeto-sistema-web-mvc-e-sql |
| 3º | banco-de-dados-avancado · programacao-orientada-a-objetos-2 · projeto-back-end-monolitico-com-orm · testes-automatizados · projeto-front-end-web |
| 4º | banco-de-dados-nosql · interface-humano-computador · projeto-aplicacao-para-dispositivos-moveis · projeto-back-end-microsservicos-e-nosql · sistemas-distribuidos |
| 5º | inteligencia-computacional · producao-de-relatorio-artigo-e-monografia · seguranca-em-sistemas-para-internet · topicos-especiais-1 |

Notas:
- `node_modules`, builds, `.venv`, pastas nativas (`ios/`, `android/`) e credenciais **não** são versionados.
  Em projetos Expo/React Native rode `npm install` (e `npx expo prebuild` se precisar das pastas nativas).
- Arquivos `*.alt-faculdade` são versões alternativas de um mesmo arquivo encontradas ao unificar duas cópias do material.
